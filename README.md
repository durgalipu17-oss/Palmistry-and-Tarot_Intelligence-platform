# AI Palmistry & Tarot Intelligence Platform

An AI-powered full-stack web application that analyzes palm images and generates tarot-based interpretations with personalized insights.

## Features

- User authentication (register/login)
- Palm image analysis
- Tarot interpretation
- Reading history dashboard
- User profile management
- FastAPI backend
- React frontend
- TensorFlow-based ML pipeline

## Tech Stack

**Frontend:** React, CSS, Axios

**Backend:** FastAPI, SQLAlchemy, SQLite

**AI/ML:** TensorFlow, Keras
